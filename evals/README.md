# Evals

Evaluations check whether the Agentic Engineering System produces useful, bounded, evidence-backed engineering behavior.

## First Evaluation Areas

- Discovery stops when enough information is known and records remaining unknowns.
- Project bootstrap creates the expected repository structure without inventing product decisions.
- Task contracts include allowed changes, forbidden changes, approval triggers, validation commands, and completion evidence.
- Verification reports map evidence to acceptance criteria.
- Retrospectives distinguish local project issues from reusable central-system issues.

## Evaluation Case Format

Each future eval should include:

- scenario;
- input;
- expected output;
- pass criteria;
- failure modes;
- notes.

## Current Status

No executable evaluations are present in version `0.1.0`. The next milestone should add dry-run cases for project discovery and project bootstrap.
