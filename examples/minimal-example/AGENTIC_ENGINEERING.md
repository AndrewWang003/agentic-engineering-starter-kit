# Agentic Engineering System

## Instance Identity

- System: Agentic Engineering SYS
- Instance type: Managed project example
- Source-kit identity: Example generated from the portable source kit
- Source-kit version or commit: Status: Recorded by the initializing Agent

## Local Workflow

- Canonical project rules: `AGENTS.md`
- Canonical local Skills: `.agents/skills/`
- Canonical templates: `templates/`
- Project state: `PROJECT.md` and `DEVELOPMENT.md`
- Task records: `tasks/`

## Upgrade Policy

Do not synchronize from a source kit automatically. Adopt a later system version only through an approved task in this project.
