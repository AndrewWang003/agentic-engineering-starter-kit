# AGENTS.md

This directory is a minimal example of a managed Agentic Engineering SYS project. A real initialized project also carries local `.agents/skills/` and `templates/` directories; this static example does not duplicate the source kit's full workflow package.

Read `AGENTIC_ENGINEERING.md` first for the instance boundary, then use local project rules and local Skills when they exist. Do not synchronize this example or another project from the source kit automatically.

These instructions apply to the minimal example project.

## Repository Structure

- `PROJECT.md` describes the project.
- `AGENTS.md` describes how Codex should work.
- `DEVELOPMENT.md` records current status, checks, risks, and next steps.
- `tasks/` stores task contracts and reviews.

## Allowed Working Behaviour

- Inspect before editing.
- Keep changes small.
- Record medium and large tasks in `tasks/`.
- Create checkpoint commits only when an approved task contract authorizes them and the slice is complete and verified.

## Forbidden Behaviour

- Do not add cloud storage.
- Do not add a database without approval.
- Do not claim completion without a check.

## Definition Of Done

- The change is summarized.
- Relevant checks are run or marked unverified.
- Remaining risks are reported.

## Approval Required

Ask before adding dependencies, changing scope, or adding persistence.
