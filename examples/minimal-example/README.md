# Minimal Example

This example shows the smallest useful project structure created from the Codex Engineering Starter Kit.

It contains:

- `AGENTIC_ENGINEERING.md`
- `PROJECT.md`
- `AGENTS.md`
- `DEVELOPMENT.md`
- `tasks/`

No application code is included. The example demonstrates the managed-project identity; a real `start-project` initialization also copies the local `.agents/skills/` workflow package and all templates.
