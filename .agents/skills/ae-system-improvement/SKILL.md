# ae-system-improvement

Use this skill when a retrospective or feedback file suggests a reusable improvement to Agentic Engineering System.

## Goal

Review evidence, decide whether the improvement is reusable, and update the central system only through controlled change management.

## Procedure

1. Read the feedback and supporting evidence.
2. Decide whether the issue is reusable beyond one project.
3. Draft or update a system improvement proposal.
4. Add evaluation coverage where practical.
5. Update affected docs, templates, skills, or scripts.
6. Update `development log.md`.
7. Update `CHANGELOG.md` and `VERSION` when releasing.

## Output

An approved and verified central system change, or a rejected proposal with reasons.

## Approval Boundary

Material changes to autonomy, approval boundaries, templates, or skill behavior require user approval.
