# ae-retrospective

Use this skill after task verification.

## Goal

Capture lessons from a completed or blocked task and decide whether any issue should become reusable central-system feedback.

## Procedure

1. Read the task contract and verification report.
2. Summarize the outcome.
3. Record what worked and what did not.
4. Classify issues:
   - Current-task issue
   - Current-project issue
   - Testing issue
   - Documentation issue
   - Reusable workflow issue
   - Central-system issue
5. Generate central feedback only for reusable workflow or central-system issues.

## Output

A task retrospective and, when justified, a system improvement proposal or feedback file.

## Approval Boundary

Do not directly modify central system rules from a retrospective. Use the system improvement workflow.
