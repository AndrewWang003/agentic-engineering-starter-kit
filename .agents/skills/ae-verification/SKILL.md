# ae-verification

Use this skill when validating whether a task is complete.

## Goal

Verify task completion against explicit acceptance criteria and evidence.

## Procedure

1. Read the task contract.
2. Review acceptance criteria.
3. Run approved validation commands when available.
4. Perform relevant manual checks.
5. Record results in a verification report.
6. List unresolved items honestly.

## Output

A verification report that includes command results, manual checks, unresolved items, and a completion claim.

## Stopping Condition

Stop when each acceptance criterion has a result and the completion claim is supported by evidence.

## Approval Boundary

If validation requires new tools, destructive operations, external services, or changed acceptance criteria, request approval first.
