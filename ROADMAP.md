# Roadmap

## Version 0.1.0: Central System Initialization

- Define system charter, architecture, workflows, templates, skills, evals, and development log.
- Include the minimal task loop: contract, execution, verification, retrospective, and system improvement.
- Keep the system file-based and lightweight.
- Do not bootstrap real projects yet.

## Version 0.2.0: Discovery Dry Run

- Test `ae-project-discovery` in a simulated project conversation.
- Refine the discovery stopping rule.
- Add at least one evaluation case for discovery quality.

## Version 0.3.0: Bootstrap Dry Run

- Test `ae-project-bootstrap` against an empty sample directory.
- Verify the generated project structure and contract placeholders.
- Add bootstrap evaluation cases.

## Version 0.4.0: Task Contract Execution Loop

- Test task contract creation, execution, verification, and retrospective in a sample project.
- Add amendment handling.
- Add evidence checks for completion reports.

## Version 0.5.0: System Feedback Loop

- Convert sample retrospectives into central improvement proposals.
- Add evaluation-before-change rules.
- Define release checklist for central system updates.
